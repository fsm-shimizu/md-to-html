# セット検査用 SPEC（fail: basename の大文字小文字違い衝突）

fail 原因は「`SPEC-a.md` と `spec-a.md` の衝突」1つだけ。

衝突相手の `spec-a.md` は**コミットしない**。大文字小文字を区別しない FS（macOS 既定の APFS）では
同一ディレクトリに両者を置けず、チェックアウト時に片方が失われて作業ツリーが壊れるため。
テスト側がこの fixture を一時ディレクトリへ複製し、FS が大文字小文字を区別する場合のみ
`spec-a.md` をランタイム生成して衝突を作る（区別しない FS では理由付き skip）。
