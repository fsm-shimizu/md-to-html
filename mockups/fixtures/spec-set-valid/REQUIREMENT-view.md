# セット検査用 REQUIREMENT

セットビルドが複数文書を1回のコマンドで処理できることを確かめる。

## 背景

- [README](./README.md) に収録文書の一覧がある
- 仕様は [SPEC](./SPEC-view.md) に置く

### 前提

このセットは検査専用であり、実際の設計内容は持たない。

## 要件

| # | 要件 | 対応 |
|---|---|---|
| R1 | セット内の相互リンクが解決する | [SPEC の参照節](./SPEC-view.md#参照) |
| R2 | 索引ハブから全文書へ到達できる | 索引 |
| R3 | 添付・画像が壊れない | [添付テキスト](./attach/notes.txt) |
